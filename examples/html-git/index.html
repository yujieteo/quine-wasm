html-git
git init · add · commit · branch · merge · push — in one HTML file, no libraries
This browser cannot open local folders. html-git needs the File System Access API directory picker (window.showDirectoryPicker), which is only available in desktop Chromium browsers: Google Chrome, Microsoft Edge, Opera, Brave, Vivaldi (version 86 or newer). Firefox and Safari do not support it.

Git, in a single HTML file.

Pick a folder on your disk. html-git reads and writes its real .git directory, so everything it does can be inspected, continued or undone with ordinary command-line git.

Supported: init, add, commit -m, branch (create / list / switch), merge (fast-forward and three-way), push (smart HTTP). Works from file:// in desktop Chrome, Edge and other Chromium browsers.

      List, create and switch branches (git branch, git switch). Switching requires a clean working tree.

        Create branch

        Merge another branch into the current one (git merge). Fast-forwards when possible, otherwise creates a merge commit. Conflicts stop the merge: fix the files, stage them with add, then commit.

        The merge commit uses the author name and email from the commit tab.

        Upload a branch to an HTTPS remote with the git smart HTTP protocol (git push). Only fast-forward pushes are allowed.

        Browsers only let a page talk to servers that send CORS headers. GitHub, GitLab and most hosts do not, so pushing to them from a web page needs a CORS proxy; the request becomes <proxy>/<remote URL without https://>. A proxy sees your token, so only use one you trust or run your own. Self-hosted servers that allow CORS work directly.
