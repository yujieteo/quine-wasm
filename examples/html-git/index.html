html-git
git init · add · commit · diff · stash · log · branch · merge · rebase · reset · push — in one HTML file, no libraries
This browser cannot open local folders. html-git needs the File System Access API directory picker (window.showDirectoryPicker), which is only available in desktop Chromium browsers: Google Chrome, Microsoft Edge, Opera, Brave, Vivaldi (version 86 or newer). Firefox and Safari do not support it.

Git, in a single HTML file.

Pick a folder on your disk. html-git reads and writes its real .git directory, so everything it does can be inspected, continued or undone with ordinary command-line git.

Supported: init, add, commit -m, branch (create / list / switch), merge (fast-forward and three-way), diff, stash, rebase, reset (soft / mixed / hard, and unstaging), log, a commit tree graph of all branches and push (smart HTTP). Works from file:// in desktop Chrome, Edge and other Chromium browsers.

              Browsers only let a page talk to servers that send CORS headers. GitHub, GitLab and most hosts do not,
        so pushing to them from a web page needs a CORS proxy; the request becomes <proxy>/<remote URL without https://>.
